# Muutosloki

Merkittävät käyttäjälle näkyvät muutokset kirjataan tähän tiedostoon.

## [1.0.0] - 2026-10-05

Ensimmäinen Go-julkaisu.

- Markdown-checkbox-tehtävien luku, listaus, lisäys, valmistuminen, uudelleenavaus, tilan vaihto ja arkistointi.
- Repo-, käyttäjä- ja projektiscopet sekä käyttäjäkohtainen TOML-asetustiedosto.
- Tekstimuotoinen roadmap-komento ja kirjoittava Bubble Tea + Lipgloss -TUI.
- `tx`-binäärin oletuskäynnistys TUI:hin; `tasx`-binäärin oletuskäynnistys listaukseen.
- Tagipohjaiset Windows-, Linux- ja macOS-jakelupaketit sekä SHA-256-tarkistussummat.
- Suoraan linkitettyjen Go-riippuvuuksien lisenssitiedostot jakelupaketissa.
- MIT-lisenssi.

Windowsin TUI:n interaktiivinen tarkistus on erillinen julkaisuportti; GitHub Actions luo tagista draft-julkaisun manuaalista hyväksyntää varten.
