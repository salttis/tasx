# Tasx-dokumentaatio

Tämä hakemisto kuvaa Tasxin tavoitellun toiminnan ja Go-version tämänhetkisen toteutuksen.

## Oppaat

- [Käyttö](./usage.md) — nykyiset Go-komennot, TUI ja asennus.
- [Julkaisu](./release.md) — v1.0-portit, versiointi, julkaisuputki ja asennuksen palautus.
- [Asetukset](./configuration.md) — `~/.tasxrc`, ympäristömuuttujat ja scopen valinta.
- [Tehtävätiedoston formaatti](./task-file-format.md) — tallennusmalli ja Go-parserin tämänhetkinen kattavuus.
- [Arkkitehtuuri](./architecture.md) — ohjelman paketit, vastuut ja riippuvuudet.
- [Kehittäminen](./development.md) — paikallinen build, ajaminen ja muutosten validointi.

## Suunnittelu

- [Projektisuunnitelma](./project-plan.md) — tavoite, rajaus, onnistumiskriteerit ja siirtymän periaatteet.
- [Roadmap](./roadmap.md) — vaiheistus ja hyväksymiskriteerit.
- [Koneellisesti luettava roadmap](../.ai/roadmap.md) — tavoite-, vaihe-, hyväksymiskriteeri- ja riippuvuustiedot, joita `tasx roadmap` näyttää tekstinä.

## Totuuden lähteet

- Toteutuksen nykyinen käyttäytyminen: Go-lähdekoodi.
- Pitkäikäiset tekniset päätökset: [.ai/decisions.md](../.ai/decisions.md).
- Suunnitellut tulokset ja etenemisvaiheet: [.ai/roadmap.md](../.ai/roadmap.md) ja tämän hakemiston laajempi [roadmap](./roadmap.md).

Roadmap ei itsessään muuta tehtävälistoja tai niiden tiloja.
